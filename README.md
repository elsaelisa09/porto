# Elsa Elisa Yohana Sianturi - Portfolio Website

A modern, responsive portfolio website built with React and Vite, showcasing expertise in Data Science, Data Analytics, and Data Engineering.

## 🚀 Features

- **Modern Design**: Clean, professional interface with orange/black color scheme
- **Responsive Layout**: Fully responsive design optimized for desktop, tablet, and mobile
- **Interactive Elements**:
  - Scroll animations with Card Stacking Effect
  - Hover effects on toolkit items and project cards
  - Expandable experience sections
  - Awards showcase with slider
- **Contact Integration**: Direct email links and social media connections
- **Performance Optimized**: Built with Vite for fast development and production builds

## 🎯 Sections

1. **Hero Section** - Introduction with role badge and character illustration
2. **About Me** - Professional bio with focus areas (Data Analytics, Data Engineering, AI/ML)
3. **Toolkit** - Technology stack showcase with interactive hover effects
4. **Projects** - Portfolio projects with detailed tech stack and roles
5. **Experience** - Work history with expandable details
6. **Awards** - Achievements and recognitions with image slider
7. **Contact/Footer** - Contact information and navigation links

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: CSS with custom animations and transitions
- **Icons & Images**: Custom SVG icons and illustrations
- **Deployment**: Optimized for static hosting

## 📱 Responsive Design

- Mobile-first approach with breakpoints at 760px
- Adaptive layouts for different screen sizes
- Touch-friendly navigation elements
- Optimized images and assets for mobile performance

## 🎨 Design Features

- **Color Scheme**: Primary orange (#FF3F15) with black/white accents
- **Typography**: Clean, readable font stack
- **Animations**:
  - Scroll-triggered fade-in effects
  - Staggered card animations
  - Smooth hover transitions
  - Panel swipe animations
- **Accessibility**: Semantic HTML, ARIA labels, keyboard navigation support

## 🚦 Getting Started

### Prerequisites
- Node.js 16+ and npm/yarn

### Installation
```bash
# Clone the repository
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🔧 Development

- **Development Server**: Runs on `http://localhost:5173`
- **Hot Module Replacement**: Enabled for fast development
- **Linting**: Oxlint configuration for code quality
- **Build Optimization**: Vite's built-in optimization for production
